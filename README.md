# MILLING INTRODUCTION – Media Pembelajaran Interaktif Praktik Frais Dasar

Media Pembelajaran Digital Resmi **Teknik Manufaktur – Section Milling Politeknik ATMI Surakarta**.

---

## 📌 Deskripsi Project
Platform web interaktif ini dirancang untuk mendigitalisasi materi Praktik Frais Dasar berdasarkan 2 sumber materi utama:
1. `MILLING INTRODUCTION.pptx`
2. `Materi Mill.pdf`

Website ini memberikan ruang belajar full-width modern, lengkap dengan fitur kalkulator kecepatan potong, tracking progress belajar, kuis evaluasi, serta checklist K3L & 5R.

---

## 🛠️ Fitur Utama
1. **Top Navigation Bar Modern (No Sidebar)** – Memaksimalkan area konten pada layar desktop dan mobile.
2. **Light & Dark Mode** – Didukung CSS variables dan `localStorage` persistence.
3. **Kalkulator Milling Interaktif** – Perhitungan otomatis RMP ($n$) dan Feeding ($s$).
4. **Pencarian Global (Global Search)** – Memudahkan pencarian alat potong, aksesori, dan parameter.
5. **Dashboard Progress Belajar** – Melacak status modul yang sudah dipelajari.
6. **20 Soal Evaluasi Interaktif** – Uji pemahaman mandiri bagi mahasiswa.
7. **Identitas Resmi Instruktur & Institusi** – Menyajikan profil instruktur Dedi Kristanto & Aditya Wahyu Handoko dari Politeknik ATMI Surakarta.
